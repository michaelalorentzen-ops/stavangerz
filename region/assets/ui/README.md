# M3 command-center assets

Created 01.11.2026 with the built-in imagegen tool. These are fictional illustrations, not photographs documenting actual properties or people. The original PNGs are preserved; WebP copies are used by the app and embedded in the portable HTML. No external image service is needed at runtime.

- `survivors-atlas-v1.png` / `survivors-atlas-v1.webp`: 2 × 2 portrait atlas. Ingrid top left, Marius top right, Leila bottom left, Tor bottom right. CSS shows the appropriate quadrant without changing the source image.
- `locations-atlas-v1.png` / `locations-atlas-v1.webp`: 2 × 2 location atlas. Residential camp top left, sports annex top right, grocery bottom left, industrial harbor bottom right. The interface labels these as illustrations.

## Final portrait prompt

Create a production game UI asset: a precisely aligned 2 by 2 grid of four square survivor portrait paintings, no borders, no text, no lettering. Each quadrant is one separate close-up head and shoulders portrait, centered and filling its whole quadrant. Dark gritty realistic painted character art for a Scandinavian zombie survival strategy game. Desaturated olive, charcoal, cold grey, weathered natural faces, subtle film grain, dramatic soft overcast side light, very dark neutral background. Top left: Ingrid, Norwegian female scout aged 30, dark blonde hair tucked in a charcoal beanie, practical hooded rain jacket, alert perceptive expression. Top right: Marius, Norwegian male hunter aged 45, dark knit cap, short salt-and-pepper beard, green outdoor jacket and shoulder strap, serious expression. Bottom left: Leila, female nurse aged 34 with medium olive complexion, dark tied-back hair, weathered grey rain jacket with a small muted medical cross patch, composed empathetic expression. Bottom right: Tor, male mechanic aged 50, broad face, ginger-grey stubble, faded dark work cap, rugged industrial work jacket, sturdy expression. Consistent portrait scale and lighting across all four squares. Believable ordinary survivors rather than futuristic soldiers. No weapons in foreground, no zombies, no UI, no background scenery. This atlas will be used in four interactive survivor cards.
